# صناديق خاصة وموازنة أعضاء هيئة التدريس ومعاونيهم

برنامج إدارة صناديق أعضاء هيئة التدريس ومعاونيهم وموازنتهم - كلية الحاسبات والذكاء الاصطناعي - جامعة بني سويف

## التصميم
هشام محمد عيد عبد السلام - مدير كلية الحاسبات والذكاء الاصطناعي

## التقنيات
- Next.js 16 + TypeScript
- Tailwind CSS 4 + shadcn/ui
- Prisma ORM (SQLite)
- Zustand
- ExcelJS (استيراد/تصدير Excel)
- jsPDF + html2canvas (تصدير PDF)
- pdf.js (استخراج نص PDF)

## التشغيل
```bash
bun install
bun run db:push
bun run dev
```

افتح المتصفح على `http://localhost:3000`

## الدخول الافتراضي
- المستخدم: `admin`
- كلمة المرور: `admin123`

## المميزات
- 6 تابات: الإعدادات، المستخدمين، الإجازات، الداتا، التقارير، المقارنة
- استيراد/تصدير Excel
- تصدير PDF (يدعم العربية)
- مقارنة PDF مع Oracle
- الجمع التلقائي للمكافآت
- حرمان الإجازات من المكافآت
- التوقيعات في أسفل التقرير
- ترويسة مخصصة بالشعارات
